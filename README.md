# RAMO Gift Card

کارت هدیه‌ی رمزارزی روی شبکه‌ی BNB Chain (USDT / USDC) با ۳۲ طرح (از جمله ۷ طرح تصویری تولد و ۵ طرح تصویری عاشقانه). رابط کاربری به فارسی، عربی، انگلیسی، اسپانیایی و چینی در دسترس است؛ متن کارت فونت، اندازه و چرخش قابل تنظیم دارد و نوشته‌های چاپی را می‌توان جابه‌جا کرد و رنگ هرکدام را تغییر داد. فرستنده با کیف پول خودش پرداخت می‌کند؛
گیرنده در تلگرام کارت و یک کیف پول تازه با ۱۲ کلمه‌ی بازیابی می‌گیرد.

## امنیت (اصل پروژه: ما هیچ کلیدی نگه نمی‌داریم)
- کیف هدیه **در مرورگر فرستنده** ساخته می‌شود. ۱۲ کلمه فقط هنگام ارسال برای چند ثانیه در حافظه‌ی Worker است تا به تلگرام برسد؛ در KV، لاگ یا هیچ‌جای دیگر نوشته نمی‌شود.
- هیچ خزانه‌ی پولی و کلید خصوصی‌ای روی سرور نیست. پرداخت‌ها مستقیم از کیف فرستنده به کیف هدیه و به **آدرس کارمزد** می‌رود و Worker آن‌ها را روی زنجیره بررسی می‌کند (حداقل ۳ تایید).
- پرداخت به کاربر تلگرام بسته است: کارمزد شامل یک کد سفارش کوچک است که فقط برای همان کاربر ثبت شده؛ پس کسی نمی‌تواند تراکنش دیگران را برای سفارش خودش استفاده کند.
- تا وقتی هدیه تحویل نشده، ۱۲ کلمه فقط در مرورگر خود فرستنده نگه داشته می‌شود تا با بستن صفحه پولی گم نشود. بعد از تحویل پاک می‌شود.

## ساختار
- `api/worker.js`: Cloudflare Worker (یک فایل، بدون وابستگی). تست: `cd api && npm test`
- `site/`: سایت React (موبایل‌پسند، در Mini App تلگرام هم کار می‌کند)

## راه‌اندازی Worker
1. Cloudflare → Workers & Pages → Worker به نام `ramo-giftcard-api` → Edit code → محتوای `api/worker.js` را بگذارید → Deploy.
2. Settings → Bindings → KV namespace: نام `GIFT_KV`، namespace همان که ساخته‌اید.
3. Settings → Variables and secrets:
   - Secret `BOT_TOKEN`: توکن بات `@ramofinance_alerts_bot`
   - Variable `FEE_ADDRESS`: آدرس BNB Chain **کیف خودتان** برای دریافت کارمزد (حتماً کیفی که کلیدش دست شماست)
   - Variable `ADMIN_CHAT_IDS`: شناسه‌ی عددی ادمین‌ها با کاما
   - اختیاری: `ALLOWED_ORIGINS`, `FEE_USD` (پیش‌فرض 0.5), `MIN_GIFT`, `MAX_GIFT`, `SENDER_COPY` (`false` یعنی نسخه‌ی فرستنده در تلگرام ارسال نشود)
4. قبل از راه‌اندازی عمومی آدرس قرارداد USDT و USDC را در BscScan دوباره چک کنید (بالای `worker.js`).

## راه‌اندازی سایت
1. GitHub → Settings → Pages → Source: **GitHub Actions**. با هر push روی `main` سایت منتشر می‌شود:
   `https://ramofinance.github.io/ramo-giftcard/`
2. BotFather → `/setdomain` → بات را انتخاب کنید و `ramofinance.github.io` را بدهید (برای دکمه‌ی ورود با تلگرام).

## توسعه و build محلی
از ریشه‌ی مخزن برای اجرای نسخه‌ی توسعه:
```sh
cd site
npm install
npm run dev
```
برای build سازگار با GitHub Pages:
```sh
cd site
VITE_BASE_PATH=/ramo-giftcard/ npm run build
```
اجرای آزمون‌های Worker:
```sh
cd api
npm test
```

## مراحل بعدی
1. سایت کامل (همین نسخه) ← تست با مبلغ کم.
2. تست موبایل در مرورگر کیف پول (Rabby / Trust / MetaMask).
3. اضافه شدن به Mini App به‌عنوان سرویس جدید؛ برای این‌که داخل تلگرام هم کیف وصل شود، اتصال WalletConnect لازم است.

## محدودیت‌ها
- گیرنده باید یک‌بار بات را استارت کرده باشد (ربات نمی‌تواند اول پیام بدهد). سایت قبل از پرداخت این را بررسی می‌کند.
- KV رایگان روزی ۱۰۰۰ نوشتن دارد (هر هدیه ۴ تا)، یعنی حدود ۲۵۰ هدیه در روز.
